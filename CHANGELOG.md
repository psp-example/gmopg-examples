# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-14

### Added
- Initial monorepo structure with pnpm workspaces
- Shared packages:
  - `@gmopg/types`: Type definitions for GMO Payment Gateway API
  - `@gmopg/utils`: Utility functions for payment processing
  - `@gmopg/api-client`: API client library for GMO Payment Gateway
- Payment method examples:
  - Credit card payment example
  - Convenience store payment example
  - Bank transfer (Pay-easy) payment example
- Use case demo:
  - Simple checkout demo with multiple payment methods
- Comprehensive documentation and README files
- TypeScript support with strict type checking
- Development scripts for building and type checking
