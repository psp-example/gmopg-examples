# @gmopg/types

Type definitions for GMO Payment Gateway API.

## Usage

```typescript
import { 
  CreditCardTransactionRequest, 
  CVSTransactionRequest,
  GMOPGConfig 
} from '@gmopg/types';
```

## Available Types

- Common types: `GMOPGResponse`, `TransactionInfo`, `TransactionStatus`
- Payment methods: `PaymentMethod`, `CreditCardInfo`, `CVSType`
- Request types: `CreditCardTransactionRequest`, `CVSTransactionRequest`, `BankTransferRequest`
- Configuration: `GMOPGConfig`
